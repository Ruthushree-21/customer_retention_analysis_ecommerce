# Customer Purchase Behaviour & Retention Analysis 

##  Project Title
A Study to Analyze Customer Purchase Behaviour and Sentiment for Predicting Customer Retention on E-Commerce Platforms Using Machine Learning and Power BI

##  Overview
This project analyzes online shopper behaviour, satisfaction, and retention patterns using statistical analysis, machine learning, and Power BI dashboards. It was completed as part of my MBA Business Analytics academic coursework.

##  Tools & Technologies
- Power BI
- Python
- Machine Learning
- Jamovi

##  Key Areas of Analysis
- Customer Purchase Behaviour
- Customer Satisfaction & Sentiment
- Customer Retention
- Customer Demographic Analysis (Age, Gender, Occupation)
- Correlation & Regression Analysis
- Machine Learning-based Retention Prediction
- Interactive Power BI Dashboard

## Dashboard Highlights
- Total Customers
- Average Purchase Behaviour
- Average Satisfaction
- Average Retention
- Age & Gender Distribution
- Occupation & Shopping Frequency
- High vs Low Retention
- Satisfaction vs Retention
- Purchase Behaviour vs Retention

## Key Insight
There is a strong relationship between customer satisfaction and retention — customer experience plays a major role in building long-term relationships with customers.
